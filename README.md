# 媒体加密解密工具

## 软件介绍

媒体加密解密工具是一款运行于 Windows 的桌面小程序，用于把本机的图片和视频
处理成**无法直接观看**的形式，再凭加密时生成的密钥文件还原回来。

需要说明的是：本工具做的是**像素置乱与逐帧异或**，属于「防随手翻看」级别的
内容遮蔽，**不是密码学意义上的加密**。它不适合用来保护高价值或高度敏感的
数据——如果你需要对抗有意的破解，请使用专业的加密软件（如 VeraCrypt、7-Zip
的 AES-256 加密）。

## 实现原理（如实说明）

### 图片

把图片的像素矩阵展开成一维序列，用 `numpy.random.shuffle` 生成一个随机下标
序列，按这个序列重新排列像素，再存成 PNG。

像素颜色值一个都没改，只是位置被打乱了，所以**解密是无损的**。
密钥文件（`.key`）里保存的就是这张置换表，外加原始颜色模式和原始扩展名。

### 视频

逐帧读取画面，把每个像素的 B、G、R 分量分别与同一个 8 位整数（0～255）
做按位异或，再写回。异或运算自反，用同一个数再算一遍就还原了，所以加密和
解密用的是同一套代码。

音频不做任何处理，原样提取出来再合并回去，因此音质不受影响。

> **关于强度**：视频密钥只有 256 种可能，图片密钥是随加密文件一起保存的
> 置换表。这两种方式都不构成密码学保护，请在了解这一点的前提下使用。

## 支持格式

- **图片**：JPG、JPEG、PNG、BMP、GIF（加密后统一输出为 PNG）
- **视频**：MP4、AVI、MOV、WMV、MKV（输出为 MP4，无 FFmpeg 时为 AVI）
- **密钥**：`.key` 文件，加密时自动生成

## 使用方法

### 加密操作

1. 打开软件
2. 选择媒体类型（图片或视频）
3. 点击「浏览」选择要加密的文件
4. 确认操作类型为「加密」
5. 点击「执行操作」
6. 完成后会生成加密文件和对应的密钥文件

### 解密操作

1. 打开软件
2. 选择媒体类型（图片或视频）
3. 点击「浏览」选择要解密的加密文件
4. 选择操作类型为「解密」，此时界面会多出一行「密钥路径」
5. 点击「浏览」选择加密时生成的同名 `.key` 密钥文件
6. 点击「执行操作」
7. 完成后会生成还原后的文件

## 功能特性

- **像素置乱 / 逐帧异或**：见上文「实现原理」，请注意其强度边界
- **无损还原**：只改变像素位置或整体异或，解密结果与原始文件一致
- **音频保留**：视频加密时音频轨道原样保留（需安装 FFmpeg）
- **进度显示**：实时显示处理进度与已处理帧数
- **操作取消**：处理过程中可随时点击「取消」中止任务
- **硬件加速自适应**：自动检测 OpenCL / UMat，可用时在显卡上运算
- **单文件处理**：每次处理一个文件；结果文件名带时间戳，多次处理不会互相覆盖

## 运行环境

- **操作系统**：Windows 10 / 11（64 位）
  （旧版本依赖 Python 3.x，在 Windows 7 上未经测试，不建议使用）
- **Python 版本**：3.8 及以上（源码方式运行时需要）
- **依赖库**：
  - NumPy 2.0 及以上
  - OpenCV（opencv_python）
  - Pillow
- **可选组件**：FFmpeg（用于视频音频的提取与合并，建议安装并加入系统 PATH；
  未安装时视频仍可加密，但输出文件不含音频，且格式回退为 AVI）

安装依赖：

```bash
pip install -r requirements.txt
```

启动：

```bash
python src/main.py
```

## 打包成 exe

打包参数全部固化在 `pixecrypto.spec` 里（单文件、无控制台窗口、禁用 UPX 压缩、
显式声明隐藏导入），因此换一台机器也能得到一致的结果。用打包脚本调用：

```bash
python build_exe.py            # 打包，产物输出到 dist/
python build_exe.py --smoke    # 打包后顺便启动一次，确认主窗口能出现
python build_exe.py --dry-run  # 只做环境自检，不执行打包
```

打包前会自检 Python 版本、10 个源码文件、以及 PyInstaller / NumPy / OpenCV /
Pillow / tkinter 是否齐全；`dist/` 里同名的旧 exe 会先自动备份到
`dist/_previous/<时间戳>/`，不会被直接覆盖。

打完包建议再跑一次验收脚本：

```bash
python verify_exe.py
```

它会真实启动 exe、通过界面各完成一次加密与解密，并逐像素比对还原结果是否与
原图完全一致，同时确认产物保存在 exe 同目录的 `媒体\` 下。

## 注意事项

1. **密钥保存**：密钥文件是还原的唯一凭据，软件不保存副本、不提供找回功能。
   丢失密钥即等于丢失原始文件，请务必单独备份。
2. **成对保管**：加密文件与密钥文件必须一一对应。文件名中的「_密钥」是识别依据，
   不要改名，也不要用文本编辑器打开。
3. **不要二次编码**：加密后的视频不要裁剪、转码或压缩，任何重新编码都会改变
   像素值，导致无法还原。
4. **文件备份**：加密前请保留原始文件，先用解密功能验证一次密钥可用，
   再决定是否删除原文件。
5. **磁盘空间**：置乱后的画面失去帧间相似性，压缩率下降，加密视频通常比原文件大，
   建议预留两倍以上空间。
6. **性能要求**：处理大视频耗时较长，具体时长与分辨率、总帧数、是否含音频有关。
7. **兼容性**：部分特殊编码的视频可能无法正常处理。
8. **不要重复加密**：对已加密的文件再次加密会使密钥与文件失去对应关系。
