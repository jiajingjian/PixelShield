## 三、video_utils.py 核心功能

### 3.1 函数列表

| 函数 | 功能 |
|------|------|
| `check_ffmpeg()` | 检查 FFmpeg 是否可用 |
| `has_audio(input_video)` | 检查视频是否有音频流 |
| `extract_audio(input_video, output_audio)` | 从视频提取音频 |
| `merge_audio_video(video, audio, output)` | 合并视频和音频，输出为 MP4 |

### 3.2 merge_audio_video 输出格式

- **视频编码**：libx264（H.264）
- **音频编码**：AAC
- **输出格式**：MP4
- **压缩质量**：CRF 23（平衡质量与大小）

## 四、加密流程更新

### 4.1 完整加密流程

```
原始视频
    ↓
1. 生成 8 位密钥
    ↓
2. 检测是否有音频
    ↓
3. [有音频] 提取音频（不加密）
    ↓
4. OpenCV 读取视频帧
    ↓
5. BGR → RGB（防偏色）
    ↓
6. 像素异或加密（OpenCV 向量化）
    ↓
7. RGB → BGR（防偏色）
    ↓
8. 写入临时 AVI
    ↓
9. FFmpeg 合并音频 + 重新编码为 H.264
    ↓
加密视频（MP4 格式，有音频）
```

### 4.2 密钥数据更新

密钥文件现在保存：
- `algorithm`: 'simple_xor'
- `key`: 8 位密钥
- `original_ext`: 原始扩展名
- **`has_audio`**: 视频是否有音频（新增字段）

## 五、解密流程更新

### 5.1 完整解密流程

```
加密视频（MP4 格式）
    ↓
1. 读取密钥（获取 has_audio 标记）
    ↓
2. [有音频] 从加密视频提取音频
    ↓
3. OpenCV 读取视频帧
    ↓
4. BGR → RGB（防偏色）
    ↓
5. 像素异或解密（相同密钥自动还原）
    ↓
6. RGB → BGR（防偏色）
    ↓
7. 写入临时 AVI
    ↓
8. FFmpeg 合并音频 + 重新编码为 H.264
    ↓
解密视频（MP4 格式，有音频）
```

## 六、容错机制

### 6.1 FFmpeg 不可用时

- 自动回退到 AVI 格式
- 音频不可保留（纯视频流）

### 6.2 音频提取失败时

- 继续加密/解密视频画面
- 输出无音频视频
- 不会中断程序

### 6.3 FFmpeg 合并失败时

- 自动回退到 AVI 格式
- 音频不可保留
- 清理临时文件

## 八、使用方法

### 8.1 启动程序

```bash
python main.py
```

### 8.2 使用步骤

1. 选择 **"视频"** 类型
2. 选择 **"加密"** 或 **"解密"**
3. 选择文件
4. 执行操作

## 九、技术优势

| 特性 | 说明 |
|-----|------|
| **音频不加密** | 原始音频直接复制，不影响音质 |
| **防偏色** | 严格 BGR↔RGB 转换流程 |
| **高性能** | OpenCV 向量化运算 |
| **兼容性好** | MP4 + H.264，播放器兼容性最佳 |
| **容错强** | FFmpeg 失败时自动回退到 AVI |
| **向后兼容** | 旧版本密钥仍可正常解密 |
